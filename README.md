custom domain via `CNAME`, DNS-only CNAME at Cloudflare). The business card's

  headings, Inter body, JetBrains Mono labels; GrabAm lime `#e8ff48`, Siryn
  coral `#e0726c` on `#0b0a10`.

Content rule: every claim must be true today. Anything in progress is labelled
in progress.
